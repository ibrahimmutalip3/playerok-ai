# Playerok AI Userbot

Telegram-userbot на базе **Telethon**, который работает от имени вашего **второго аккаунта (твинка)** и отвечает **только в одной группе Playerok**. Ответы генерирует AI-модель, которая подражает вашему стилю общения по файлу `messages.json`, но **не копирует** из него сообщения.

---

## ⚠️ Прочитайте перед запуском

1. **Это автоматизация от имени реального человека.** Если бот пишет в группе, люди будут думать, что это пишет живой человек (твинк). Правила Telegram и правила самой группы Playerok могут запрещать автоматические ответы. **Проверьте правила группы и Telegram перед запуском. Ответственность за использование лежит на вас.**
2. **Бот не должен обманывать людей.** На прямой вопрос «ты бот?» он отвечает нейтрально («Почему спрашиваешь?»), а не отрицает, что он автоматический.
3. **Не делитесь файлами `.env`, `*.session` и `messages.json`.** Это ваши ключи, доступ к аккаунту и личные переписки.
4. **Не используйте основной аккаунт.** Для бота используется только твинк.

---

## 1. Что вам понадобится

- Аккаунт GitHub (бесплатный): https://github.com
- Второй Telegram-аккаунт (твинк), который уже состоит в группе Playerok
- Telegram API ID и API Hash (инструкция в разделе 3)
- API-ключ AI-сервиса, совместимого с OpenAI (например, OpenAI, OpenRouter и т.п.)
- Файл `messages.json` с вашими личными сообщениями (экспорт из Telegram)

## 2. Запуск через GitHub Codespaces (пошагово)

### Шаг 2.1. Загрузите проект на GitHub

1. Откройте https://github.com/new и создайте **приватный** репозиторий (Private), например `playerok-ai`.
2. Нажмите **«uploading an existing file»**.
3. Распакуйте архив `playerok-ai.zip` на своём компьютере и перетащите **все файлы и папку `.devcontainer`** в окно загрузки.
4. **Не загружайте** `messages.json`, если хотите держать его приватно вне GitHub (см. шаг 2.4 — его можно загрузить в Codespaces вручную).
5. Нажмите **Commit changes**.

### Шаг 2.2. Создайте Codespace

1. Откройте ваш репозиторий на GitHub.
2. Нажмите зелёную кнопку **Code → Codespaces → Create codespace on main**.
3. Подождите 1–2 минуты. Откроется редактор VS Code в браузере. Зависимости установятся автоматически (`requirements.txt`).

### Шаг 2.3. Добавьте секреты (рекомендуется)

Секреты лучше хранить в Codespaces Secrets, а не в файле. Так они не попадут в код.

1. На GitHub откройте **Settings** (ваш профиль) → **Codespaces** → **Codespaces secrets** → **New secret**.
2. Создайте по одному секрету для каждой переменной из раздела 4:
   - `TELEGRAM_API_ID`
   - `TELEGRAM_API_HASH`
   - `PLAYEROK_CHAT_ID`
   - `OWNER_ID`
   - `AI_API_KEY`
   - (остальные необязательны, см. раздел 4)
3. В поле **Repository access** выберите ваш репозиторий `playerok-ai`.
4. Чтобы новые секреты подхватились, **перезапустите Codespace**: меню **Codespaces → Stop current codespace**, затем снова откройте его.

> Альтернатива: создайте файл `.env` (скопируйте `.env.example` в `.env` и заполните). Файл `.env` не попадёт в GitHub.
> В терминале: `cp .env.example .env`, затем откройте `.env` в редакторе и заполните значения.

### Шаг 2.4. Загрузите messages.json

1. В левой панели Codespace (проводник файлов) перетащите ваш `messages.json` в корневую папку `playerok-ai`.
2. Убедитесь, что файл лежит рядом с `main.py`.

### Шаг 2.5. Установите зависимости вручную (если не установились сами)

В терминале внизу выполните:

```bash
pip install -r requirements.txt
```

## 3. Как получить Telegram API ID и API Hash

1. Откройте в браузере https://my.telegram.org
2. Войдите по номеру телефона **твинка** (введите код из Telegram).
3. Нажмите **API development tools**.
4. Заполните форму: App title — любое, например `playerok-helper`; Short name — любое латинскими буквами; Platform — Other.
5. Нажмите **Create application**.
6. Вы увидите **App api_id** (число) и **App api_hash** (строка из букв и цифр). Это `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.

**Никому не показывайте api_hash.** Бот никогда не выводит его в логи.

## 4. Список переменных окружения

| Переменная | Обязательна | Что это |
|---|---|---|
| `TELEGRAM_API_ID` | да | число из my.telegram.org |
| `TELEGRAM_API_HASH` | да | строка из my.telegram.org |
| `PLAYEROK_CHAT_ID` | да | ID группы Playerok (шаг 6) |
| `OWNER_ID` | да | ваш личный Telegram ID (узнать у бота `@userinfobot`) |
| `AI_API_KEY` | да | ключ AI-сервиса |
| `AI_BASE_URL` | нет | адрес API, по умолчанию `https://api.openai.com/v1` |
| `AI_MODEL` | нет | модель, по умолчанию `gpt-4o-mini` |
| `AI_TIMEOUT` | нет | таймаут запроса к AI, сек (по умолчанию 30) |
| `TELEGRAM_SESSION_NAME` | нет | имя файла сессии (по умолчанию `twink_session`) |
| `AUTH_METHOD` | нет | `qr` (по умолчанию) или `phone` |
| `REPLY_PROBABILITY` | нет | дополнительный вероятностный фильтр участия, 0.0–1.0 (по умолчанию 0.5) |
| `MIN_REPLY_DELAY` | нет | минимальный интервал между отправками, сек (по умолчанию 5) |
| `MAX_REPLY_DELAY` | нет | верхняя граница задержки (по умолчанию 7) |
| `BATCH_WINDOW` | нет | сколько ждать, пока пишут несколько сообщений подряд (по умолчанию 3) |
| `CONTEXT_SIZE` | нет | сколько последних сообщений группы видит AI (по умолчанию 30) |
| `STYLE_SAMPLE_SIZE` | нет | сколько примеров из `messages.json` учитывать (по умолчанию 40) |
| `MESSAGES_FILE` | нет | путь к файлу стиля (по умолчанию `messages.json`) |
| `LOG_FILE` | нет | файл логов (по умолчанию `userbot.log`) |

## 5. Первая авторизация твинка (QR-код)

При первом запуске бот попросит войти в аккаунт твинка.

1. Запустите бота (раздел 7).
2. В терминале появится **QR-код**.
3. На телефоне, с которого управляете **твинком**, откройте Telegram:
   **Настройки → Устройства → Подключить устройство** и отсканируйте QR-код.
4. Если включена двухфакторная защита (облачный пароль), бот попросит его ввести. Вводимые символы скрыты, это нормально.
5. После успеха файл `twink_session.session` создастся рядом с `main.py`. **Не отправляйте его никому.** Повторно входить не придётся, пока сессия активна.

Если QR не работает, в `.env` (или в секретах) поставьте `AUTH_METHOD=phone`. Тогда бот попросит номер телефона твинка и код из Telegram.

## 6. Как узнать ID группы Playerok

1. Убедитесь, что твинк уже состоит в группе Playerok.
2. Выполните в терминале:

```bash
python main.py --list-chats
```

3. Появится список групп и каналов с ID. Найдите нужную группу и скопируйте её ID (он обычно начинается с `-100`).
4. Вставьте его в переменную `PLAYEROK_CHAT_ID`.

При запуске бот также выведет название и ID найденной группы и проверит, что это именно группа (не личный чат и не канал). Всё остальное он игнорирует.

### Команды управления

**Из Telegram** (отправляйте их с **вашего личного аккаунта** в личном чате с твинком; работают только для `OWNER_ID`):

| Команда | Что делает |
|---|---|

stop
start
stats

## 10. Как работает `messages.json`

- Это экспорт ваших личных сообщений в формате списка. Пример:

```json
[
  { "chat": "Ivan", "date": "2024-05-01T10:00:00", "text": "Привет, как дела?" }
]
```

- Бот **не копирует** эти сообщения и **не отправляет** их AI как готовые ответы. Из них извлекаются признаки стиля: средняя длина, пунктуация, эмодзи, скобки, сленг, регистр и т.п.
- Эти признаки описываются в системной инструкции для AI, а сами тексты сообщений туда не попадают.
- Каждый ответ генерируется заново по текущему контексту группы.
- Чтобы обновить стиль, замените `messages.json` и выполните `/reload`.

## 11. Как устроена логика ответа

1. Бот получает новое сообщение из **разрешённой группы**. Сообщения из других чатов игнорируются.
2. Если пришло несколько сообщений подряд, бот подождёт `BATCH_WINDOW` секунд и ответит на всю пачку сразу.
3. Собирается контекст: последние `CONTEXT_SIZE` сообщений группы.
4. AI решает, есть ли смысл вмешаться (не на всё нужно отвечать, спам и повторы пропускаются).
5. Дополнительно срабатывает вероятностный фильтр `REPLY_PROBABILITY`. Прямые обращения к твинку (Reply на его сообщение или упоминание) этот фильтр не блокирует.
6. AI пишет новый ответ, избегая повторов недавних.
7. Бот делает случайную задержку 3–10 секунд, имитирует набор текста и отправляет ответ.
8. Между отправками соблюдается минимум `MIN_REPLY_DELAY` секунд.
9. Если Telegram попросил подождать (FloodWait), бот **ждёт указанное время** и не пытается его обойти.

## 12. Перенос на постоянный сервер

Codespace — временная среда, её могут остановить или удалить. Для постоянной работы:

1. Возьмите любой Linux-сервер (VPS) с Python 3.10+.
2. Скопируйте папку проекта, включая `.env` и `twink_session.session` (передавайте их безопасно, по SSH/SFTP). **Не выкладывайте их в интернет.**
3. На сервере выполните:

```bash
cd playerok-ai
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
nohup python main.py > run.out 2>&1 &
```

4. Проверить работу: `tail -f userbot.log`.
5. Остановить: `pkill -f "python main.py"`.

Для автозапуска после перезагрузки сервера можно использовать `systemd` или `crontab @reboot`. Если сессия сбросилась, повторите авторизацию (раздел 5).

## Частые проблемы

| Проблема | Что делать |
|---|---|
| `Не задана переменная окружения ...` | Заполните секрет или `.env` |
| `PLAYEROK_CHAT_ID указывает ...` | Проверьте ID через `python main.py --list-chats` |
| `Не удалось найти чат` | Убедитесь, что твинк состоит в группе |
| QR-код не сканируется | Используйте `AUTH_METHOD=phone` |
| `AI временно недоступен` | Проверьте `AI_API_KEY`, баланс и `AI_BASE_URL` |
| `FloodWait` в логе | Бот сам подождёт нужное время. Ничего делать не нужно |
| Бот молчит | Посмотрите `/status` и `/stats`; возможно, включён `/stop` или AI решил не отвечать |
